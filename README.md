# 海峡观察在线展示版

马六甲与新加坡海峡公开报告与事件研究。网站提供地图、月份筛选、原始报告、案例对照、已保存的AI分析与区域简报。

这是发布时的只读资料快照。报告记载、分析推断和待核信息分别展示，AI草稿与后续修改意见保留原状态。

## 发给朋友

通过微信、QQ或网盘发送整个ZIP。朋友先完整解压，再双击“打开海峡观察.html”，即可在浏览器查看。保留所有子文件夹，页面和材料需要一起使用。

## GitHub Pages 发布

将本目录中的全部内容提交到专门的GitHub仓库根目录，保留目录层级和隐藏文件 .nojekyll。在仓库 Settings 页面进入 Pages，选择 Deploy from a branch，再选择 main 和 /(root)，保存后等待部署。

默认首页为事件地图，进入工作台可使用 dashboard.html。分享工作台时，在GitHub生成的网址后加 dashboard.html。

上传的是解压后的网页文件，ZIP本身不会自动成为网站。目录中文件较多，建议用GitHub Desktop克隆仓库后，将本目录内容复制到克隆目录，再提交并推送。

## 使用说明

公开站点只包含网页和展示数据。已有AI回答、重建报告、核对意见和简报可阅读与下载。采集、计费生成和写入在本机研究版进行。

地图底图依赖OpenStreetMap网络服务，报告页图片和已归档PDF随站点提供。原报告版权属于原发布机构，出处、版本和引用页码随页面保留。

更新网站时，在本机重新导出，再替换发布目录。这里不包含AI密钥、Python服务或SQLite数据库。
